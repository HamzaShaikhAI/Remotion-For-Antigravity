## ⚡ Instant Setup

Run anywhere in your terminal or inside Google Antigravity:

```bash
# Using npm
npx create-remotion-antigravity my-video-studio

# Using pnpm
pnpm dlx create-remotion-antigravity my-video-studio

# Using yarn
yarn create remotion-antigravity my-video-studio
```

---

## 📦 What's Included

Every generated workspace includes:
- **Preconfigured Remotion 4.0 Studio**: Immediate access to `remotion preview` and `remotion render`.
- **Dual Landscape & Vertical Compositions**: Out-of-the-box support for 16:9 4K/1080p landscape documentaries and 9:16 60fps vertical viral reels.
- **Strict TypeScript & Deterministic Animation**: Zero `Math.random()` guarantees concurrent frame consistency.
- **Full REA Integration**: Pre-linked to `antigravity-remotion-skills` for autonomous agent-driven cutting, procedural SFX synthesis, loudness mastering, and neural upscaling.

---

## 🚀 Running Your Studio

```bash
cd my-video-studio

# Install dependencies
npm install

# Start visual preview
npm start

# Render master MP4
npm run build
```
